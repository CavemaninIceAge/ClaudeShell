# Claudex Shell

Ein nativer macOS-Arbeitsbereich für Claude Code und Codex.

Die Kontowahl gilt nur innerhalb von Claudex Shell. „Push to terminal“ und „Push to Codex App“ sind getrennte, ausdrückliche Aktionen. Claude-, GLM- und Codex-Anmeldungen können lokal gespeichert werden. Codex CLI und Desktop teilen ihren Anmeldespeicher; laufende Clients müssen möglicherweise erneut geöffnet werden.

[English — full documentation](README.md) · [简体中文](README.zh-Hans.md)

```sh
./scripts/build.sh Release
./scripts/test.sh
./scripts/install.sh
```
