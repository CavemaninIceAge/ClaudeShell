# Claudex Shell

同時支援 Claude Code 與 Codex 的原生 macOS 對話工作台。

選擇帳號只影響 Claudex Shell。「推送至終端」和「推送至 Codex App」是另外的明確操作。可保存本機 Claude、GLM、Codex 登入狀態。Codex CLI 與桌面端共用登入快取，已執行的客戶端可能需要重新開啟。

[English — full documentation](README.md) · [简体中文](README.zh-Hans.md)

```sh
./scripts/build.sh Release
./scripts/test.sh
./scripts/install.sh
```

macOS 15+ · Swift 6 · XcodeGen
