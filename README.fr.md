# Claudex Shell

Un espace de travail macOS natif pour Claude Code et Codex.

Le choix du compte ne change que Claudex Shell. « Push to terminal » et « Push to Codex App » sont des actions explicites distinctes. Les connexions locales Claude, GLM et Codex peuvent être enregistrées. La CLI et le bureau Codex partagent leur cache de connexion ; un client déjà ouvert peut nécessiter une réouverture.

```sh
./scripts/build.sh Release
./scripts/test.sh
./scripts/install.sh
```
